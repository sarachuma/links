Руководство по управлению Архивами

Для Стримера и Модераторов

Главная команда в примерах: !заказ (подставьте свою из Streamer.bot: !filmzakaz, !fz, !gamezakaz, !gz и т.д.).
Ручное добавление (Без баллов)
!заказ @ник Название (add)
Добавляет заказ в очередь от имени указанного зрителя. Алиасы: (заказ), (order), (add)
Победа на аукционе
!заказ @ник Название (аукцион)
Добавляет заказ со статусом ✦ Аукцион ✦. Алиасы: (аукцион), (auction), (аук)
Пройдено / Смотрели с оценкой
!заказ Название (8.5)
Закрывает заказ и выставляет вашу оценку (от 0 до 10).
Пройдено / Смотрели (Без оценки)
!заказ Название (смотрели/прошли)
Переводит из очереди в «Смотрели/Пройдено».
⚠️ Повторный ввод вернет статус «В очереди»! Алиасы: (смотрели), (посмотрели), (watched) Алиасы: (пройдено), (complete), (прошли)
Добавить метку «Слёзы»
!заказ Название (слёзы)
Добавляет метку 💧 для эмоциональных игр/фильмов. (Только для просмотренных/пройденных). Алиасы: (слёзы), (плакал), (cry)
Можно комбинировать: (8.5) (слезы)
Удаление из базы
!заказ Название (удалить)
Полностью стирает заказ зрителя из базы. Алиасы: (удалить), (delete), (del), (убрать)
Удаление по нику+ID: !заказ @ник 12 (удалить)
Замена заказа
!заказ Старое [Новое]
Заменяет текущий заказ на другой. Новое название нужно писать строго в квадратных [ ] или фигурных { } скобках.
Пример: !заказ Начало [Шрек 2]
Принудительное обновление
!заказ (обновить)
Если сайт не обновился автоматически, эта команда заставит бота отправить базу данных еще раз. Алиасы: (обновить), (update), (refresh)
